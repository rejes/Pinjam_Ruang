# Tugas Challenge — Fitur "Cari Ruangan yang Cocok"

Syarat mulai: proyekmu sudah lulus `npm run uji` 32/32.

1. Salin `uji-tantangan.mjs` dan `package.json` ke folder proyekmu (timpa `package.json` yang lama).
2. Jalankan `npm run uji:tantangan`. Skor awal 0/10.
3. Tulis fungsi `cariRuanganCocok(daftar, jumlahOrang, kataFasilitas = '')` di `helper.js` sampai skor 10/10.
4. Tambahkan form pencarian di `index.html` dan tampilkan hasilnya lewat `main.js`.
5. Pastikan `npm run uji` tetap 32/32.

Spesifikasi lengkap ada di Lembar Tugas Challenge dari guru.
